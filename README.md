# 🔐 Password Strength Checker

A Python-based Password Strength Checker available as both a desktop application and a web application.

## 🌐 Live Demo

[Open Password Strength Checker](https://password-strength-checker-p2e2.onrender.com/)

## Features

- Password strength score from 0 to 5
- Weak, Medium, and Strong classification
- Password requirements checklist
- Show and hide password
- Generate strong passwords
- Copy password to clipboard
- Visual strength progress bar
- Desktop Tkinter application
- Flask web application
