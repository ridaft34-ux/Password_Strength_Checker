# 🔐 Password Strength Checker

A simple desktop application built with Python and Tkinter to check password strength.

## Features

- Password strength score from 0 to 5
- Weak, Medium, and Strong classification
- Password requirements checklist
- Real-time character counter
- Real-time requirement checking
- Show and hide password
- Generate strong passwords
- Copy password to clipboard
- Clear all fields
- Visual strength progress bar
- Responsive interface when resizing the window

## Technologies Used

- Python
- Tkinter

## How to Run

1. Install Python.
2. Download or clone this project.
3. Open the project folder.
4. Run:

```bash
python Password_gui.py
